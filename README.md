# kairoku-plugin — retired

This repository is archived. The Kairoku plugin restarted from scratch as
`plugin/` **inside the app repository**: https://github.com/bikerwhocodes/kairoku

Install the current plugin from there:

```
/plugin marketplace add <path-or-url-of-the-kairoku-repo>
/plugin install kairoku@kairoku-marketplace
```

Why the restart, and what was salvaged: epic
[KAIR-303](https://owds-ca.atlassian.net/browse/KAIR-303). The salvage source
was this repo's branch `story/KAIR-267-plugin-config` @ a5492bc, kept intact
here for the record.
